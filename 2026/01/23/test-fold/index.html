Mermaid 图表测试

这是一个大型流程图，应该会自动添加折叠按钮：

flowchart TD
    Start([开始]) --> CheckNull{Animation == null?}
    
    CheckNull -->|是| ErrorNull[报错 - 无效动画]
    CheckNull -->|否| CheckRootMotion{有根运动?}
    
    ErrorNull --> End([结束])
    
    CheckRootMotion -->|否| ErrorRootMotion[报错 - 未启用根运动]
    CheckRootMotion -->|是| AddCurve[添加 CurveName 曲线]
    
    ErrorRootMotion --> End
    
    AddCurve --> GetLength[获取动画长度 AnimLength]
    
    GetLength --> CheckStopAtEnd{bStopAtEnd?}
    
    CheckStopAtEnd -->|是| SetEndTime[TimeOfMinSpeed = AnimLength]
    CheckStopAtEnd -->|否| SearchMinSpeed[搜索最小速度点]
    
    SearchMinSpeed --> InitSearch[初始化
SampleInterval = 1/120秒
NumSteps = AnimLength / SampleInterval]
    
    InitSearch --> LoopSearch{Step 小于 NumSteps?}
    
    LoopSearch -->|是| ExtractMotion[提取根运动
RootMotionTranslation]
    
    ExtractMotion --> CalcSpeed[计算速度平方
SpeedSq = 位移² / SampleInterval]
    
    CalcSpeed --> CheckSpeed{SpeedSq 小于 MinSpeedSq?}
    
    CheckSpeed -->|是| UpdateMinSpeed[更新 MinSpeedSq
更新 TimeOfMinSpeed]
    CheckSpeed -->|否| NextSearch[Step加1]
    
    UpdateMinSpeed --> NextSearch
    NextSearch --> LoopSearch
    
    LoopSearch -->|否| GenerateCurve[生成距离曲线]
    SetEndTime --> GenerateCurve
    
    GenerateCurve --> InitCurve[初始化采样
SampleInterval = 1/SampleRate
NumSteps = 向上取整长度]
    
    InitCurve --> LoopCurve{Step 小于等于 NumSteps
且 Time 小于 AnimLength?}
    
    LoopCurve -->|是| CalcTime[Time = min Step*SampleInterval, AnimLength]
    
    CalcTime --> CheckTime{Time 小于 TimeOfMinSpeed?}
    
    CheckTime -->|是| SetSign[ValueSign = -1.0f
接近中]
    CheckTime -->|否| SetSignPos[ValueSign = 1.0f
远离中]
    
    SetSign --> ExtractRange[提取根运动范围
TimeOfMinSpeed 到 Time]
    SetSignPos --> ExtractRange
    
    ExtractRange --> CalcDistance[计算距离
Distance = 模]
    
    CalcDistance --> AddKey[添加关键帧
Time 到 ValueSign * Distance]
    
    AddKey --> NextCurve[Step加1]
    NextCurve --> LoopCurve
    
    LoopCurve -->|否| End
