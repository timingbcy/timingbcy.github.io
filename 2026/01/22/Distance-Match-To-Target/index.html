Distance Match To Target

说到distance match to target，这其实是个unreal里的动画节点，用在locomotion里的，主要做的事情一句话说就是：根据给定一个距离，让当前动画到对应距离播完，计算当前的动画应该播哪一帧。这说的和鬼话一样，但是再换个角度说，其实就是，把我们原来通过时间来驱动的动画改成了通过位移或者说距离来进行计算的。现在不是当前时刻应该播放啥动画了，是当前位置应该播放啥动画了。

Root Motion

既然我们提到了距离，那势必要知道的就是，我的这个距离是怎么算的呢？我怎么知道到目标位置我需要让我的动画走多远？于是，我们首先来讨论下距离的计算方式。

这里的距离不是简单的说我这个角色一共从动画开始移动了多少距离，也不是我当前位置距离原点有多远，他有一套很有意思的计算方式。我们多看几根曲线就能发现，这些曲线说是距离，但是居然还会有负数的。具体原因我们来根据源码分析一下。源码在unreal 5.7里面的名字叫做void UDistanceCurveModifier::OnApply_Implementation(UAnimSequence* Animation)，这是一个类，但是主要就是这个函数，这里不放源码了，就先讲一下思路，然后给个伪代码，方便想看的家人们自己去看。

在内部他会有一个TimeOfMinSpeed的float的变量，这个变量其实就是表示这根距离曲线的零点，在这个时刻，我的距离就是0，并且这个距离曲线一定是单调递增的，所以如果这个零点在最开始，那么整根曲线就是全正的，在最末尾那就全是负的，当然他也会有在中间的情况，那就是前一半负的后一半正的。三种曲线对应的三种情况就是，起步（最开始的时候速度是0），停止（结束的时候速度是0），掉头（速度降到0再加速）要注意的是，这里的速度的方向我们是不关心的。当然你说会不会有那种0开始加速再减速到0的，是有的，但是我们这里不做讨论，家人们想知道是什么样的自己去做一个对应的动画就可以了。

说到这里，提一嘴，上面说的所有的动画距离，都是root motion的，我们后面实际计算距离的时候会发现，我们得到了距离之后还得把root motion删掉的，这样才能保证我的动画是个原地动画，我都通过代码计算距离来控制动画了，root motion肯定是没用了，相信这个也很好理解。

在之后，我们会按照一个小的step来计算速度，就是两帧之间的root motion做差就可以了，如果发现了我们的速度比之前的都小，就让这个时刻作为我们的零点，到这里其实大家就能发现了，就算是我加速在减速，我们在第一次速度为0的时候，后一次只要速度不是负的（这是不可能的）他就不会更新，于是其实就是一个S型的正数曲线而已。

计算得到零点之后，我们只要根据采样率，每帧计算当前的root motion的位置，然后计算和零点的root motion的距离，就可以得到两者的距离了，然后如果时间在零点前，直接加个负号就可以了，到此，整个距离曲线的计算就搞定了，当然这个曲线的负数在distance match to target里用的不是很明显，它在后续会用在别的内容里，但是本文先不做讨论。

如果还看不懂的话，我这里还有个流程图：

flowchart TD
    Start([开始]) --> CheckNull{Animation == null?}

    CheckNull -->|是| ErrorNull[报错 - 无效动画]
    CheckNull -->|否| CheckRootMotion{有根运动?}
    
    ErrorNull --> End([结束])

    CheckRootMotion -->|否| ErrorRootMotion[报错 - 未启用根运动]
    CheckRootMotion -->|是| AddCurve[添加 CurveName 曲线]
    
    ErrorRootMotion --> End
    
    AddCurve --> GetLength[获取动画长度 AnimLength]
    
    GetLength --> CheckStopAtEnd{bStopAtEnd?}
    
    CheckStopAtEnd -->|是| SetEndTime[TimeOfMinSpeed = AnimLength]
    CheckStopAtEnd -->|否| SearchMinSpeed[搜索最小速度点]
    
    SearchMinSpeed --> InitSearch[初始化 SampleInterval = 1/120秒 NumSteps = AnimLength / SampleInterval]
    
    InitSearch --> LoopSearch{Step 小于 NumSteps?}

    LoopSearch -->|是| ExtractMotion[提取根运动 RootMotionTranslation]
    
    ExtractMotion --> CalcSpeed[计算速度平方 SpeedSq = 位移² / SampleInterval]
    
    CalcSpeed --> CheckSpeed{SpeedSq 小于 MinSpeedSq?}

    CheckSpeed -->|是| UpdateMinSpeed[更新 MinSpeedSq 更新 TimeOfMinSpeed]
    CheckSpeed -->|否| NextSearch[Step加1]

    UpdateMinSpeed --> NextSearch
    NextSearch --> LoopSearch
    
    LoopSearch -->|否| GenerateCurve[生成距离曲线]
    SetEndTime --> GenerateCurve
    
    GenerateCurve --> InitCurve[初始化采样 SampleInterval = 1/SampleRate NumSteps = 向上取整长度]
    
    InitCurve --> LoopCurve{Step 小于等于 NumSteps 且 Time 小于 AnimLength?}

    LoopCurve -->|是| CalcTime[Time = min Step*SampleInterval, AnimLength]
    
    CalcTime --> CheckTime{Time 小于 TimeOfMinSpeed?}

    CheckTime -->|是| SetSign[ValueSign = -1.0f 接近中]
    CheckTime -->|否| SetSignPos[ValueSign = 1.0f 远离中]

    SetSign --> ExtractRange[提取根运动范围 TimeOfMinSpeed 到 Time]
    SetSignPos --> ExtractRange
    
    ExtractRange --> CalcDistance[计算距离 Distance = 模]

    CalcDistance --> AddKey[添加关键帧 Time 到 ValueSign * Distance]

    AddKey --> NextCurve[Step加1]
    NextCurve --> LoopCurve
    
    LoopCurve -->|否| End

Sequence Evaluator

有了曲线之后，我们要做的事情是找到动画的一帧，这个很简单，其实就是从动画里给一帧的frameId或者一个time时间，来获取对应的姿态数据就可以了，只是因为和传统的sequence player不一样我们这里单独拿出来提一嘴而已，不展开谈，但是这里再unreal的节点里，你可以给他绑定几个对应的回调函数，这里回调的执行流程也和我们以前知道的回调很像，这里会先获取evaluator的数据，然后执行回调逻辑，再把对应的输出返回给evaluator，从而达成一些复杂的操作。我们的distance match to target就是要放在回调里的。

Distance Match To Target

说完上面的，我们先来说一下这个节点是干什么的，它做的其实还蛮简单的，就是我告诉你一个距离，你就知道在这个距离之后你要到达指定的位置，并且在这个位置，你会让你的动作运行到0点，这样就可以从时间驱动改成了距离驱动了，这里这个节点就是用来算这个距离对应的时间的，有了这个时间之后，我们到Sequence Evaluator里去找对应的pose，给到输出，就可以获取当前帧的动画了。还是很好理解的，我们一样来看一下伪代码和流程，对应的代码是unreal里的：FSequenceEvaluatorReference UAnimDistanceMatchingLibrary::DistanceMatchToTarget(const FSequenceEvaluatorReference& SequenceEvaluator, float DistanceToTarget, FName DistanceCurveName)。

flowchart TD
    Start([开始]) --> CallNode[调用动画节点函数 DistanceMatchToTarget]
    
    CallNode --> GetSequence[获取动画序列 SequenceEvaluator.GetSequence]
    
    GetSequence --> CheckAnim{AnimSequence != null?}

    CalcTime --> Explain[约定: 距离曲线存储负值]
    
    Explain --> Negate[取反距离 -DistanceToTarget]
    
    Negate --> CallGetPos[调用 GetAnimPositionFromDistance AnimSequence, -DistanceToTarget, DistanceCurveName]
    
    CallGetPos --> GetResult[获得 NewTime]
    
    GetResult --> SetTime[设置显式时间 SequenceEvaluator.SetExplicitTime]
    
    SetTime --> CheckSuccess{设置成功?}
    
    CheckSuccess -->|否| WarningDynamic[警告: 无法设置显式时间 值不是动态的]
    CheckSuccess -->|是| Return
    
    WarningDynamic --> Suggest[提示: 设置为 Always Dynamic]
    Suggest --> Return

到这里就会发现，整个流程就结束了，我们从一个root motion开始，到这里可以通过距离来进行控制了，这在locomotion里面用的还蛮多的，很多急停啊，加速都需要用到的，也算是在locomotion里前进了一步吧。
