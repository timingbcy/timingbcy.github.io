示例文章 - 如何正确设置分类和标签

test博客教程

示例文章内容

这篇文章展示了如何在 Hexo 中正确设置文章的分类和标签。

Front-matter 格式

在文章的开头，需要使用 YAML 格式设置元数据：

分类（Categories）

  • 支持多级分类，例如：[技术, Hexo] 表示 技术 > Hexo
  • 如果是单个分类，可以写成：categories: Hexo
  • 如果是多个分类，使用数组格式：categories: [教程, Hexo]

标签（Tags）

  • 标签使用数组格式
  • 例如：tags: [hexo, 教程, 博客]

常见问题

  1. 分类和标签页面为空：请检查文章的 front-matter 是否正确设置了 categories 和 tags
  2. 分类页面不显示文章：确保分类名称正确，且文章已重新生成
  3. 标签页面不显示文章：确保标签使用数组格式，且文章已重新生成

解决方法

如果分类和标签页面不显示内容：

  1. 检查文章的 front-matter 格式是否正确
  2. 运行 hexo clean 清理缓存
  3. 运行 hexo generate 重新生成
  4. 运行 hexo server 启动服务器查看效果
